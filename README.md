# 모럴 머신 교실

초등학교 5학년 인공지능 윤리 수업용 웹 활동입니다.
브레이크가 고장 난 자율주행차가 누구를 보호해야 할지 20가지 상황에서 고르고, 나의 가치판단을 세계 사람들의 경향과 비교해 봅니다.

- 사이트: https://dlrka0131-cyber.github.io/moral-machine/
- 구성: 연습 문제 → 11개 부(사람 수, 나이, 성별, 사람과 동물, 신호, 탑승자, 몸집, 직업, 임산부, 똑같을 때, 부딪히는 문제) → "이 차를 살 건가요?" → 나의 도덕 나침반, 생각해 보기, 토론 질문
- 참고: MIT Moral Machine 실험 (Awad et al., *Nature*, 2018)
